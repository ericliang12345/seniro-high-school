# 高中英文段考複習 Skill（精簡版）

## 1. 教材與範圍
- 輸入：**課本／單字表、上課錄音逐字稿、老師講義、小考考卷及訂正**（若有段考卷、雜誌一併納入）。
- 先確認出版社、課次、考試範圍、題型與配分；只把範圍內內容列為必讀。
- 依「**老師強調＋小考常出＋上次失分**」排序；缺漏資料明確註記，不猜題、不編造答案。
- 使用者若尚在上傳資料，等說「開始整理」才製作。

## 2. 五大複習重點
| 類別 | 整理與練習方式 |
|---|---|
| **單字／文意字彙** | 單字、詞性、搭配、衍生字；**看中文或句意，自己拼出英文**。 |
| **片語** | 整理固定搭配、介系詞與使用情境；**完整句子填空**。 |
| **文法** | 白話解釋→句型→易錯比較→**至少3題不同句子的變化題**。 |
| **克漏字** | 以完整短文練**轉折、因果、時間、上下文邏輯**，不只背連接詞中文。 |
| **閱讀理解** | 教**找關鍵句、主旨、細節、推論與排除錯誤選項**。 |

## 3. 依真實題型出題
- 對照老師小考與前次段考題型，設計**全新**模擬考；配分未知時標為暫定。
- 同時安排**四選一與無選項拼字／填空**；文章題保留完整上下文。
- 原題和 AI 新編題分開標示；**每題先作答→提示→答案→詳解→同觀念換題重練**。
- 錯題依「單字不熟／拼字／文法／上下文／閱讀誤判」分類，集中補強。

## 4. 輸出一頁式網站
- 使用**國中生也懂的繁體中文**，重點都包含「白話說明＋英中例句＋解題技巧＋練習」。
- 輸出**單一離線 HTML**，手機／電腦可用；答案預設隱藏、逐題詳解、計分、進度與錯題重練。
- 網站順序：**考點清單→五大教學→老師小考→模擬考→錯題救分→考前3分鐘重點**。
- 延用 `English/Prompt.md` 的詳細規格；若發布 GitHub，按根目錄 `SKILL.md` 檢查 `README.md` 索引，未授權不得推送。

## 5. 完成前確認
- [ ] 考試範圍及老師高頻考點沒有漏。
- [ ] 單字能**自行拼寫**，文法能做**新題**，克漏字與閱讀能說出**原文依據**。
- [ ] 題目、答案及詳解正確；各題可獨立顯示答案。
- [ ] 模擬考、錯題重練及離線 HTML 正常運作。

**目標：不是背考題答案，而是遇到換句子、換文章的題目也會答。**
