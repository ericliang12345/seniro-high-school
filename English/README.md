# 二段
## 課程規劃與考試規定
```
 * 段考範圍與教材：
   * 第二次段考範圍包含英文課本（第 5、6 課）、字彙書以及雜誌。
   * 第一次段考試卷難度相對較簡單，第二次段考題量與難度會增加。
   * 學習歷程或學期結束前，雜誌切勿丟棄，後續段考及學期末仍會用到。高一高二共計會累積閱讀多本雜誌。
 * 字彙書（單字書）要求：
   * 高一背的是銜接國高中的字彙，到了高二會背進階級單字書（學測高頻單字）。
   * 老師上課不會逐字帶讀單字書，學生需依照每週排定進度自行背誦。
   * 單字測驗安排： 每週四/五會發放單元卷帶回家練習與查閱，隔週週一進行該單元確認考試；每週三則固定考課本單字。
```
## 英文寫作與閱讀結構：說明文／論說文（Expository Writing）
老師以漢堡架構（Hamburger Structure）解說學測長文與閱讀測驗常見的「說明文/論說文」篇章結構（課本第 80–81 頁）：
| 結構層次 | 漢堡比喻 | 內容說明與要點 |
|---|---|---|
| Introduction（引言段） | 頂層麵包 | 提出主題句（Topic Sentence），點出全文核心議題與立場。 |
| Discussion / Body（正文段） | 中間肉片與配料 | 舉例說明、正反論證、提出論據支持主題。常出現轉折詞與列舉詞（如 First, Second, Finally）。 |
| Conclusion（結論段） | 底層麵包 | 只做重述與總結，絕對不能出現新觀點或新論點。常見訊號詞為 in short（簡而言之）。 |
