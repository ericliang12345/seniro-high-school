01｜關係子句：四步解題

Step 1｜找先行詞

人 → who / whom
物 → which
限定用法常可用 that

Step 2｜看子句缺什麼

缺主詞 → 主格，不能直接省略
缺受詞 → 受格，限定用法通常可省略

Step 3｜看逗號

無逗號 → 限定
有逗號 → 補述，不能用 that，也不能省略關代

Step 4｜看特殊提示

the only、最高級等：高中選擇題通常優先選 that

課文三句拆解

things (that) we can't smell
先行詞 things 是物；we 是主詞；smell 缺受詞，所以 that 可省略。
sniffer dogs, which use their keen sense of smell ...
which 補充說明嗅覺犬；前面有逗號，不能換成 that。
the only task that sniffer dogs can accomplish
the only 是考題提示，優先選 that；that 在子句中作受詞。
老師的速記口訣是「the only / any / every / 最高級 → that」。考試先依教材選項判斷，但這不是所有語境都絕對排除 who / which 的語法定律。另外，專有名詞或已明確的對象常用補述，但仍須看語意，不能只憑引號就判定一定要加逗號。

02｜重要句型：看到就會用

This is because + S + V

這是因為……。because 引導的原因子句接在後面。

補充例句：This is because dogs have a keen sense of smell.
far / much + 比較級

far more sensitive = 敏銳得多。

a human's 後省略重複的 sense of smell。
Here is / Here are ...

後面單數用 is，複數用 are。

such as + N

例如……，後接名詞或名詞片語。

閱讀策略｜先找 Hook，再找 Topic Sentence

Hook（吸引注意的開頭）

Have you ever noticed that dogs are able to smell things that we can't?

Topic Sentence（主題句）

老師提醒可注意第一段最後一句，如 Here are a few more interesting ways ...，它可能帶出全文將介紹的重點。

記法：開頭提問吸引人 → 段末點主題 → 正文舉例支持。 主題句的位置不是每篇都固定。
