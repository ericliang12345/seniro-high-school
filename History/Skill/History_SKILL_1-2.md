# 高一歷史段考 Skill｜從背答案到會作答

**核心目標：先聽懂歷史故事 → 不看答案自己想 → 用新題型驗證理解。**
65 分是準備目標，不是成績保證；寧可練會 50 題，也不要只背 150 個答案。

## 1. 先讀這些材料

| 來源 | 要找的重點 |
|---|---|
| **考試範圍** | 哪些章節會考；絕不沿用上次考試的內容 |
| **上課逐字稿** | 老師反覆強調、特別提醒、舉例、解題線索 |
| **老師講義／課本／板書** | 事件因果、人物、年代、政策、時間軸、地圖、史料 |
| **小考考卷／解答** | 老師真的考過的觀念、考法及易錯選項 |
| **第一次段考正式卷** | 只參考老師偏好的題型（史料、比較、因果、地圖、非選），不是下一次的範圍 |

若使用者還在上傳，等其說「傳完了／開始整理」再完整產出。缺頁、聽不清、答案矛盾要註明，不得臆測。

## 2. 五步驟：真的教會再考

**① 抓考點：** 交叉比對逐字稿、講義、小考，分成 **A 必讀／B 重要應用／C 補充**。每一點註明依據：`【老師明講／重複】`、`【小考考過】`、`【講義核心】`、`【AI 推測】`；能標頁碼或題號就標。不得把 AI 推測寫成老師必考。

**② 白話教：** 每個 A 級重點用國中生聽得懂的方式，依「**一句話 → 歷史故事（背景、原因、經過、結果）→ 時間軸／比較表 → 老師可能怎麼考**」教學。教完一小段就停下來練，避免整頁只有密密麻麻的名詞。

**③ 先答後看：** 每個重點至少有 **1 題基礎＋1 題不同問法的應用**。練習題一開始**不顯示答案或詳解**；先選答案／輸入回答，再揭示結果。答不出可按「提示」，仍不會就按「不會／跳過」，記成錯題後再看詳解。老師的示範例題可先講解，但不能讓模擬測驗答案先曝光。

**④ 換題驗證：** 同一觀念至少換一種陌生情境、史料、地圖、年代順序或政策比較題，**不能只改選項順序或重複原題**。要求學生指出「題幹線索 → 為什麼選這個 → 其他選項錯在哪」。

**⑤ 模考＋補救：** 完成一份 **50 題不看筆記的仿真卷**，分類每個錯誤：`知識不會／因果不懂／史料讀不懂／比較混淆／時地不熟／粗心`。針對錯因補教後，再給**全新變化題**測一次；隔天或考前再複習錯題。

## 3. 優先訓練的六種題型

| 類型 | 要會回答的問題 |
|---|---|
| 基本辨識 | 這個人、事件、名詞、年代是什麼？ |
| 事件因果 | 長期原因、導火線、結果、影響有何不同？ |
| 政策比較 | 不同時代的統治者為何這麼做？差在哪？ |
| 史料題組 | 誰寫的、立場是什麼、證據能支持哪個結論？ |
| 地圖與時間 | 事件發生地、遷徙路線、前後順序為何？ |
| 非選擇題 | 用關鍵名詞＋一到兩句理由回答，有沒有引用資料證據？ |

參照第一次段考，可先用「配合 5、單選 30、題組選擇 5、非選 10」作為 **50 題模考初始結構**，但下次應依實際考試公告與新小考調整。正確答案、詳解、干擾選項解析都要有；自編史料須標示「模擬史料」。

## 4. 最後只交付三個區塊（可整合為單一 HTML）

1. **20–30 分鐘考前必讀**：優先 10–15 個 A 級考點，白話故事、一張時間軸、重要比較表、老師出題線索。
2. **理解→練習互動單元**：每個核心考點「教學 → 先作答 → 看提示／解答 → 換題再考」，進度顯示「還沒學／已理解／能獨立解新題」。
3. **50 題模考＋錯題重練**：考前測驗不預先顯示答案；交卷後看分數、逐題詳解、錯誤類型與弱點回讀位置。

若使用一頁式網站：輸出**單一離線 HTML**，支援手機、逐題作答、答案預設隱藏、提示、計分與錯題重練。開放題使用給分關鍵字與自我核對，**不可宣稱能精準自動評分**。

## 5. 65 分學習檢查點

- **第一關：懂了嗎？** 能不用看答案，用自己的話說出事件的「原因＋結果」。
- **第二關：會用了嗎？** 碰到改寫的選擇題／史料題能講出線索；只認得舊題答案不算通過。
- **第三關：能穩定作答嗎？** 先以模考達 **60 分**為中繼目標，再用**兩份未見過的試卷達 70 分左右**做考前準備檢查；這不保證正式分數。
- **不通過就補教、換題，不要讓學生直接重新背正確選項。**
