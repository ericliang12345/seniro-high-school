# 高一地科段考 65+｜一頁式高命中率複習 Skill

> **與原規格搭配**：先遵守同資料夾 `Prompt.md` 的科學正確性、圖解、原卷、互動、單一離線 HTML 與 QA 要求；本 Skill 新增「**先對準考試 → 可直接閱讀學會 → 未見過的題也會解 → 用模擬題驗證**」的工作流程。若本 Skill 的題型重製需求與 `Prompt.md`「原卷不要重複轉文字」不同，原卷保留完整截圖，另行新增的同觀念變化題可使用文字呈現，並明確區分。

## 目標與本次教訓

- **能力目標**：學生看完筆記即使沒上補習，也能知道「為什麼」、懂圖表、會算題、會排除錯誤選項，並能獨立完成**陌生敘述的同觀念題**。
- **成績目標**：每題 2 分、50 題的考卷，要超過 65 分至少答對 **33 題（66 分）**；考前模擬以 **36/50 題（72 分）** 作為緩衝目標。這是訓練目標，不保證實際分數。
- **115 學年高一第一次段考反思**：正式試卷約 **39/50 題為天文相關**；先前 40 題複習大量集中於地震、板塊，造成範圍失準。此比例**只用來檢查過去備考方式，不得直接套用到下次段考**。下次必須按「**新範圍與老師實際教學**」重排內容。

## 輸入資料與優先順序

1. **必需**：這次段考公告範圍、課本章節與老師進度；不清楚時，先標記範圍待確認，不能靠版本章名自行猜測。
2. **強烈建議**：老師講義、上課錄音逐字稿／黑板圖、課堂例題、小考及訂正；以老師教過和反覆提醒的內容做出題權重線索。
3. **校準難度**：上一次正式段考原卷、學生錯題、先前筆記，辨識老師偏好的**變化題、圖表題、時間／方向推理、數據計算**，不可誤認為下一次必考章節。
4. 缺少資料時先列出「已確認範圍／待確認範圍」，繼續完成可靠部分；不臆造老師原話、考題、答案或命中率。

## 必做流程（依序執行）

### Step 1｜先做「考試範圍防呆表」，再寫筆記

輸出表格：`章節／知識點｜課本頁碼或講義來源｜老師強調／小考證據｜題型｜優先級 A/B/C｜是否已教｜是否已練`。
- **A**：在本次正式範圍內，老師強調、小考出現、是其他題的前置觀念，或重要圖表／計算；先完整教。
- **B**：在範圍內的重要基礎與常見變化；接著教。
- **C**：範圍內次要延伸；最後快速閱讀。**範圍外不為湊篇幅而加入**。
- 若章節名稱與老師講授範圍不一致，以**公告與實際教材**為主，先回報差距。不得因以前筆記做過某單元而沿用題目比例。

### Step 2｜把筆記寫成「學生可以直接讀懂的教材」

每個 A/B 級重要考點都用固定結構（不要只有背誦條列）：
1. **30 秒重點**：一句白話答案、必記名詞／公式。
2. **3 分鐘理解**：這是什麼 → 為什麼 → 發生條件／過程 → 改變條件會如何；補足需要的國中先備知識。
3. **一張清楚圖**：優先重畫天球／方位／日影／星等／天文尺度／地質剖面／時間軸等**本次範圍需要**的圖，標清角度、方向、時間、單位、觀測位置；不適合畫圖的可用比較表。
4. **完整解題示範**：題目關鍵字 → 使用觀念 → 推理或列式 → 答案 → 為何其餘選項錯。
5. **一看就懂的易錯提醒**：特別處理「看似相似、實際不同」與題目陷阱。
6. **立即練習**：基礎題 1 題＋改變條件／圖表／計算的變化題至少 1 題；預設隱藏答案，逐題看提示、詳解。

### Step 3｜照正式段考的「能力型態」練，不只背原題

按實際教材選題型，涵蓋：
- 基本概念與**容易混淆的選項**；
- 圖表／座標／方位與時間變化（圖不能只貼上，要教**先看哪裡、如何判讀**）；
- 數據、比例、單位、半衰期或其他**範圍內**的運算及反推；
- 情境題、跨觀念推理、同觀念**換數字／換敘述／換圖**。

**第一次段考教訓示例（不是下次固定範圍）**：
- 星等題：相差 2 等，亮度約差 6.3 倍；能從不同星等重新計算。
- 半衰期題：母元素：子元素＝1：7，剩下 1/8，推回 3 個半衰期。
- 恆星視運動題：分清**每天較早升起**與**同一天東升西落**，避免照抄圖示答案。
- 地質剖面題：依沉積、褶皺、侵入、斷層的**交切關係**逐步排事件先後。

### Step 4｜一次生成「直接拿來唸」的一頁式離線 HTML

頁面順序（**閱讀是主體，題庫是驗收**）：
1. **考前 15 分鐘必讀**：依 A 級知識做 10–20 條口訣＋圖表索引。
2. **核心觀念白話教學**：依 A→B→C 分組；每個知識點能在 3–6 分鐘內讀懂。
3. **老師例題與小考訂正**：遵守原 `Prompt.md` 規格保留原圖與獨立提示；不重複製作相同原卷。
4. **同觀念變化題**：每個重要觀念至少兩種問法，清楚標示「新增練習」。
5. **正式難度模擬測驗**：以**新範圍**與老師小考難度出題，不湊 40 題；題目數按素材和時間決定，足以涵蓋各重要考點。
6. **錯題→回到教學→重測**：可依知識點、錯誤原因、題型複習；顯示進度與對錯。

畫面須手機／電腦可用；單一 HTML 嵌入必要圖表、樣式和程式，無網路也能閱讀及作答；不得使用失效的外部資源。完成時提供下載，並依專案慣例更新 `README.md` 的筆記索引（僅在具有專案寫入權限或取得同意時提交）。

### Step 5｜交付前的「65 分防呆驗收」

必須附上**覆蓋率檢查表**：`本次範圍的每個老師重點 → 筆記教學位置 → 例題 → 變化題 → 學生是否會解`。
- **範圍覆蓋**：不得有 A 級重點完全缺漏；如果缺少來源資料，明示風險而不宣稱完整。
- **題目難度**：至少包含基礎、變化、圖表／推理三種，且各有獨立詳解；不能只把原題答案換順序。
- **能力驗證**：學生先閱讀後作答**未看過答案**的模擬題，目標 ≥72%；50 題規模相當於 ≥36 題。低於目標時指出最值得補的 3–5 個觀念，回到教學再測。
- **逐題 QA**：原卷選項、圖片裁切、題號、正解、錯誤選項解釋、公式、圖示、時間／方向／單位正確；不清楚的標為待核對，不猜答案。
- **結果報告**：列出 A/B/C 考點完成度、模擬成績、錯題分類、下次 30 分鐘最值得複習的項目；沒有實際測驗數據時不能聲稱學生一定會達標。

## 給學生的使用方式

**第一輪：** 先讀「考前必讀」與所有 A 級教學；**第二輪：** 每個觀念自己作一題變化題；**第三輪：** 不看答案完成混合模擬；**第四輪：** 只針對錯題回讀觀念，再做不同版本題目。**不要只背選項字母。**

## 必須交付

- `EarthScience/<本次章節>_段考互動總複習.html`：單一離線 HTML。
- 一張 `範圍→教學→例題→變化題` 覆蓋率表。
- 一段「本次目標 65+ 的補強重點與仍缺少的資料」摘要。

**最終判準：不是整理多少頁或出了多少題，而是學生能不能只靠這份筆記，理解本次考試範圍，並正確作答新情境題。**
