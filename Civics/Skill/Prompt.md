【教學特別要求】

- 不要只整理精簡筆記，每個重要觀念都必須有足夠的白話說明、具體例子及必要圖解。
- 採用「理解名詞 → 掌握制度與原理 → 生活案例應用 → 比較易混淆概念 → 練習題目 → 訂正錯誤 → 再次複習」的教學順序。
- 不要假設學生已具備完整公民基礎，遇到抽象概念應先用日常生活的例子解釋，再連結課本的正式定義。
- 每個重要知識點都盡量安排理解檢查題，確認學生不只是記住定義，而是真的知道如何應用。
- 特別強化「觀念與觀念的差異」，例如權利與義務、自由與平等、法律與道德、事實與價值判斷等，僅依教材實際範圍整理。
- 對重要制度須說明設立目的、運作機制、適用條件及影響，避免只背制度名稱。
- 涉及爭議性社會或政治議題時，應客觀說明不同觀點與論據，區分事實、價值判斷及個人意見，不以特定政治立場引導學生。
- 涉及法律規範、政府制度或政策時，應區分教材版本所描述的制度與現行規定；需要補充現況時，應查核可靠來源並註明查核日期，不得自行猜測。
- 老師上課強調的內容、例子、口訣與考題提醒，應優先整理。
- 每道選擇題都應說明其他選項錯在哪裡，幫助學生排除干擾答案。
- 每個重要觀念都盡量連結至少一道相關練習題，讓學生能立即檢查理解程度。
- 新增的教學案例與模擬題須明確標示，不得冒充老師原題或教材原文。
- 若教材有錯誤或疑似過時的內容，應明確標示差異並說明依據，不得直接當成正確知識。
- 不清楚或無法辨識的教材內容，不得自行猜測為正確答案。
