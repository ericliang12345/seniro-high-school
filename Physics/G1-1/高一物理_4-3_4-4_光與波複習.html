① 4-3 電磁波譜：先把這裡讀熟

v = f × λ　｜　λ = v ÷ f
v：波速

波每秒前進幾公尺（m/s）

f：頻率

每秒振動幾次（Hz = s⁻¹）

λ：波長

相鄰波峰間的距離（m）

真空光速 c = 3 × 10⁸ m/s

電磁波譜（由長波長到短波長）

無線電波 → 微波 → 紅外線 → 可見光 → 紫外線 → X 射線 → γ 射線

往右：波長變短、頻率變高（真空中的波速相同）。

射線名字很像，但不是同一種東西

射線本質是不是電磁波？
X 射線、γ 射線電磁波✅ 是
陰極射線、β⁻ 射線電子流❌ 否
α 射線氦原子核流❌ 否
考前口訣：「X、伽瑪是電磁；陰極、貝他是電子；阿爾法是氦核。」

4-4 新課內容

② 波：只要記住「方向、距離、時間」

橫波

振動方向 ⟂ 前進方向
例：繩波、光波

縱波
|||||　|　|　|||||　|　|
↔ 振動　　前進 →

振動方向 ∥ 前進方向
例：聲波、彈簧縱波

波長 λ

相鄰兩個波峰或波谷的距離（空間）

週期 T

振動一次花的時間（秒）

頻率 f

一秒振動幾次（Hz）

f = 1/T　　v = λ/T = fλ
最好記的兩句：頻率由波源決定；波速由介質決定。同一道波換介質，頻率不變，速度與波長可能改變。

③ 波前：看波浪排成什麼形狀

把「振動狀態相同」的點連成線，就是波前。波峰可以連成一條波前，波谷也可以。

兩個必背：前進方向垂直波前；相鄰同類波前的距離 = 1 個波長。

④ 光的本質：光既像波，也像粒子

學說人物能解釋不能完整解釋
微粒說牛頓直進、反射、折射干涉、繞射
波動說惠更斯直進、反射、折射、干涉、繞射光電效應

愛因斯坦（1905）提出光量子說，解釋光電效應。光具有波粒二象性。

看到「干涉、繞射、偏振」

想到：波動性

看到「光電效應」

想到：粒子性

看到「直進、反射、折射」

兩種歷史學說都能解釋

注意：彩虹主要以光的折射、反射及色散來說明，屬幾何光學。

⑤ 反射與折射：只看「法線」

法線就是垂直於界面的假想線。入射角、反射角、折射角都是「光線與法線」的夾角。

反射

入射角 = 反射角

折射

快 → 慢：偏向法線
慢 → 快：偏離法線

折射率 n：光在介質裡慢了多少？

n = c / v　　n ≥ 1

n 越大 → 光速越慢。光從一種介質到另一種介質，頻率不變。

n₁v₁ = n₂v₂ = c
λ₁/λ₂ = v₁/v₂ = n₂/n₁
考試提醒：老師預告目前以 n = c/v 的基本計算為主，尚不考用三角函數求折射角。

⑥ 老師例題：照這個順序解

例題 8｜已知頻率，求波長

f = 10⁴ Hz，c = 3×10⁸ m/s

λ = c/f = 3×10⁴ m

答案：C 丙區（無線電波）。注意波長單位是 m，不是 m/s。

例題 9｜哪些是電磁波？

X 射線、γ 射線是電磁波。答案：B、E。陰極射線、α、β 是粒子流。

例題 10｜三秒前 A 波峰在 D

A 到 D 有 3 個波長，總長 6 m，因此 λ = 6÷3 = 2 m。

3 秒移動 6 m，所以 v = 6÷3 = 2 m/s；f = v/λ = 1 Hz。

答案：E。

例題 11｜幾何光學現象

雨後天空彩虹，可用折射、反射與色散解釋。答案：A。

例題 12｜哪個現象證明光的波動性？

繞射是波動特有的重要證據。答案：C。

例題 13｜微粒說與波動說

直進與反射兩者皆可解釋；牛頓主張微粒說，惠更斯主張波動說；干涉需用波動說解釋。答案：A、D、E。
