01｜第一堂

電磁感應：磁生電

法拉第發現：穿過線圈的磁通量隨時間改變，會產生感應電動勢；閉合電路中就可能有感應電流。

有磁場 ≠ 一定有電流

磁鐵靜止、線圈靜止且磁通量不變 → 沒有持續感應電流。

磁通量改變 → 感應電流

磁鐵靠近、遠離，或線圈轉動，都可能讓磁通量改變。

檢流計 G

用來檢測微小電流及方向。指針偏轉要依檢流計的接線極性判讀。

一句話背熟：不是「有磁就有電」，而是「磁通量改變才感應」。
02｜第一堂必考

冷次定律：來了擋、走了拉

線圈產生的感應磁場，會反抗造成感應電流的磁通量變化，不是一律反抗原磁場。

磁鐵靠近

SN
→∿∿∿

靠近線圈的一面形成 N 極，與磁鐵 N 極相斥。

記：來了擋（同極相斥）

磁鐵遠離

SN
←∿∿∿

靠近磁鐵的一面形成 S 極，吸引遠離的 N 極。

記：走了拉（異極相吸）

若面對線圈某一端看：逆時針電流 → 該端 N 極；順時針電流 → 該端 S 極。右手四指沿傳統電流方向彎曲，大拇指指向線圈內的感應磁場（N 極方向）。
判題先看磁鐵「哪一極」靠近或遠離，再決定線圈靠近磁鐵的一端是 N 還是 S。磁鐵換成 S 極，答案也要對調。
03｜第一堂例題

感應電流如何變大？

匝數增加相同變化下感應電動勢通常更大
相對運動更快磁通量變化率通常更大
電阻較小相同感應電動勢下電流更大

嚴格來說，電流大小還受電路總電阻影響；以上是其他條件相同時的比較。

線圈與磁鐵相對速度感應情況
同向、同速0相對位置不變 → 通常無感應電流
只有一方移動v有磁通量變化
反向、各以 v 移動2v在同等幾何條件下變化較快
講義例題 4：甲：線圈向右 v、磁鐵向右 v → 相對速度 0；乙、丙：都靜止或同速 → 0；丁：線圈向左 v、磁鐵向右 v → 遠離速率 2v，感應電流最大，選 D。
04｜第一、二堂

三大生活應用

⚡ 發電機

動能 → 電能

線圈在磁場中旋轉 → 磁通量週期性變化 → 感應電動勢。

滑環：交流電 AC；分裂環換向器：方向不變的脈動直流電。

🔁 變壓器

交流電 → 變動磁場 → 感應電壓

原線圈輸入交流電，經鐵芯磁通量變化，在副線圈感應出電壓。

穩定直流電不能讓一般變壓器持續運作。

🍳 電磁爐

交流電 → 交變磁場 → 渦電流 → 發熱

鍋底感應出渦電流，因電阻產生熱；通常需使用適合感應加熱的鐵磁性鍋具。

變壓器一定要會的公式

V₁ / V₂ = N₁ / N₂

理想變壓器：V 是電壓、N 是線圈匝數；1 為原線圈、2 為副線圈。

N₂ > N₁

副線圈匝數多 → 升壓

N₂ < N₁

副線圈匝數少 → 降壓

發電機轉一整圈，交流電的方向每半圈反轉一次。判方向時要追蹤線圈的正反面與磁通量變化，不能只看磁通量「大小」增加或減少。

06｜第二堂必考

電磁波：不用介質也能傳播

電場 E、磁場 B、波的前進方向：三者互相垂直，因此電磁波是橫波。

真空也能傳

不需要空氣、水等介質。

真空波速

c ≈ 3 × 10⁸ m/s

基本關係

c = fλ；頻率越高，波長越短。

電磁波譜：左邊波長長，右邊頻率、能量高

無線電波通訊
微波微波爐
紅外線熱成像
可見光人眼可見
紫外線殺菌
X 射線醫療影像
γ 射線高能輻射
排序口訣：「無、微、紅、可、紫、X、伽」；往右 波長變短、頻率變高、光子能量變高。可見光約 400～750 nm。
大氣窗口：可見光及部分無線電波較能穿透大氣；並非所有波段都能順利到達地面。不同波段吸收程度不同。
