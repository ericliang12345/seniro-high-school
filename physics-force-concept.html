庫侖力：最容易算，但最怕一開始就亂代

先看方向，再列式。

核心公式

F = k |q₁q₂| / r²

計算「力的大小」時用電量絕對值；正負號主要拿來判斷吸引或排斥。

同性相斥、異性相吸。

萬有引力

F = G Mm / r²

這兩個公式長得很像，最大的考點就是「比值時 r² 會消掉」。

看到「電力是重力的 K 倍」→ 直接做兩個公式相除。

平衡題固定 4 步

1
畫位置
先確認第三電荷要放在線段內還是外面。
2
畫受力方向
合力為 0，兩邊力一定方向相反。
3
列「大小相等」
F左 = F右。
4
再代庫侖公式
通常 k、第三電荷 Q 都會直接消掉。

弱作用：這一章最容易被文字騙

看到「衰變」就先亮燈。

自由中子會不會一直存在？

不會。

題卷使用的說法是：自由中子不穩定，約十多分鐘尺度會經由弱作用發生 β 衰變。

n → p + e⁻ + ν̄

強力 vs 弱力作用範圍

依題卷：強力約 10−15 m；弱力約 10−18 m。

所以：強力作用範圍 ＞ 弱力作用範圍。
四種基本力中最弱的是「重力」，不是弱力。

題目卷 1～6 題：名師拆題

先自己想，再按「看名師解法」。

⏱ 20 分鐘 Q1–Q4：主題題 Q5–Q6：加分題
1
弱作用：哪個敘述錯誤？
  1. 太陽產生能量的過程與弱力有關
  2. 自由空間中的中子是穩定粒子，不會衰變
  3. 弱作用有效距離小於強力
  4. 包立為 β 衰變提出電中性粒子的假設
答案：B

抓字眼：「自由中子」＝不穩定。 自由中子會經由弱作用發生 β 衰變，所以「不會衰變」這句錯。

考場口訣：看到「衰變」→ 先想到弱力。
2
質子與電子間：庫侖力是萬有引力的幾倍？

題目給：mp=1.67×10−27 kg、me=9.1×10−31 kg、e=1.6×10−19 C。

答案：C，數量級 10³⁹

最漂亮的做法不是各算一次，而是直接相除：

K = (k e² / r²) ÷ (G mₚmₑ / r²)

r² 直接消掉：

K = k e² / (G mₚmₑ) ≈ 2.28×10³⁹
名師提醒：比值題看到兩個公式都有 r²，先找能不能消。
3
哪一個「力 → 基本作用力」配對最正確？
  1. 彈簧恢復力 → 強力
  2. 繞操場旋轉的向心力 → 弱力
  3. 地板給桌子的正向力 → 重力
  4. 桌子與地板摩擦力 → 電磁力
  5. 電子繞原子核的向心力 → 重力
答案：D

彈力、摩擦力、正向力，微觀本質都屬於電磁力。電子繞原子核主要也是庫侖力＝電磁力。

超高頻口訣：接觸力大多先想「電磁力」。
4
A 放 +q、B 放 +9q，C 放在 A、B 之間。C 受合力為 0，求 BC / AC。
答案：D，BC / AC = 3

令 AC=x、BC=y。C 平衡，所以 A、B 對 C 的力大小相等：

k·q|Q| / x² = k·9q|Q| / y²

把 k、q、|Q| 消掉：

1/x² = 9/y² → y = 3x
強的電荷要離得比較遠。B 是 9q，所以 C 必須離 B 更遠。
5
同密度星球分成 27 個等質量小星球，表面重力加速度變多少？
答案：B，變成 1/3

密度不變，所以 M ∝ R³。

M' = M/27 → R' = R/3

再用表面重力：

g = GM/R²

所以：

g'/g = (1/27) ÷ (1/9) = 1/3
星球切小題：第一步先用「密度不變 → M ∝ R³」。
6
強作用與弱作用：哪些敘述正確？（選三項）
  1. 原子核中質子與質子之間，僅有強作用力
  2. 自由中子約十多分鐘會因弱作用衰變
  3. 四種基本力中最弱的是弱作用
  4. 題卷將湯川秀樹的介子理論列為強作用理論脈絡
  5. 強作用範圍比弱作用大
答案：B、D、E

A 錯：質子之間不只強力，也有電磁力與重力。

B 對：自由中子的衰變屬弱作用。

C 錯：四大基本力最弱的是重力。

D 對：依本題卷教材脈絡，湯川秀樹的介子理論用來描述核子間強作用。

E 對：題卷給的尺度為強力約 10⁻¹⁵ m，弱力約 10⁻¹⁸ m。

最容易錯的是 A：題目出現「僅有、一定、完全」這種絕對字眼，要特別小心。

考前 3 分鐘，只背這 8 句

真的來不及就看這裡。

1. 接觸力（摩擦、正向、彈力）→ 多半是電磁力。
2. 原子核把質子、中子綁住 → 強力。
3. 粒子衰變 → 弱力。
4. 天體、重量、自由落體 → 重力。
5. 四大基本力最弱的是重力。
6. 強力作用範圍 ＞ 弱力作用範圍。
7. 庫侖平衡：先畫方向，再列 F左=F右。
8. 電力 / 重力比值：相除後 r² 通常消掉。
