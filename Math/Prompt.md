請將這次上傳的所有數學教材，製作成「高中數學一頁式互動複習網站」，最後直接提供單一 HTML 檔下載，手機與電腦皆可使用，並支援完全離線閱讀與測驗。

資料可能包含：數學課本、講義照片、老師黑板筆記、手寫解題、上課錄音或逐字稿、練習題、考卷 PDF 及詳解。

請先完整閱讀、辨識並交叉比對所有資料，依照教材實際範圍整理，不要漏掉重要內容，也不要自行加入超出教材範圍的進階知識。所有公式、計算過程與答案都必須確認正確。

網站請包含：

1. **核心觀念教學**：用最簡單的白話中文，從基礎逐步解釋每個重要數學觀念。說明「這個觀念是什麼、為什麼成立、什麼時候使用、如何應用」，不要只有公式和定義。對容易混淆的觀念，提供直觀例子與比較說明。

2. **公式與原理理解**：整理教材中的所有重要公式、定理、性質及使用條件。每個公式都必須包含「公式意義、符號說明、適用條件、使用時機、簡單範例、常見錯誤」。必要時用高中生能理解的方法說明推導過程，避免只要求學生死背。

3. **圖解與互動視覺化**：重要觀念盡量使用數線、座標圖、函數圖形、幾何示意圖、表格或步驟流程圖輔助理解。適合互動的內容，可加入參數調整、圖形變化及即時觀察功能。圖形須準確，並清楚標示座標、數值及數學意義。

4. **老師例題與逐步解題**：完整整理老師上課講解的所有例題，保留「完整原始題目截圖」與「完整老師原始解題截圖」。學生先自行思考，按「看提示」取得解題方向，再按「逐步解題」分階段顯示完整計算過程，最後按「看老師解答」顯示原始解題截圖。每一步都要解釋為什麼這樣做，不能只列出算式。

5. **題型分類與解題 SOP**：依照教材與老師例題整理常見題型。每種題型說明「如何辨識題型 → 找出已知條件 → 選擇公式或方法 → 逐步計算 → 檢查答案」。整理老師強調的速解技巧、關鍵口訣、常見陷阱及容易失分的地方。

6. **基礎到進階互動練習**：每個重要知識點都安排適量練習，分成「基礎觀念 → 公式應用 → 標準題型 → 綜合變化題」。每題提供獨立的「看提示、看下一步、看完整詳解」功能，讓學生逐步學會，而不是直接看到答案。

7. **原卷互動練習**：將提供的練習題、老師例題及考卷完整納入網站，保留原始題目截圖，包含題幹、選項、數學符號、圖形、表格及子題。題目與原始詳解必須完整配對。學生先作答，再逐步查看提示、解題步驟及完整答案。選擇題須解釋正確選項及其他選項錯誤的原因。不得將相同原卷題目重複建立成另一組文字題目。

8. **考前模擬測驗**：依教材重要觀念、老師例題及原卷常考方向，另外設計適量的段考預測題，包含基礎題、計算題、觀念判斷題、圖形題、應用題與綜合題。題目難度由簡單到進階，並明確區分原卷題與新增模擬題。提供答題紀錄、客觀題自動批改、成績統計及錯題重練。計算或證明題若無法可靠自動判分，則提供標準解答與自我檢查，不得假裝已正確批改。

9. **錯題分析與弱點補強**：依學生答題結果，將錯誤分類為「觀念不清楚、公式使用錯誤、計算失誤、題意理解錯誤、條件遺漏」。每道錯題要連結對應的教學觀念，提供補強說明及類似練習題，讓學生確認是否真正學會。

10. **考前快速總複習**：最後整理「必懂核心觀念、必背公式、公式使用條件、重要題型、解題 SOP、老師口訣、常見錯誤、易混淆觀念及考前 3 分鐘重點」，方便快速回顧整章內容。

【教學特別要求】

- 不要只整理成精簡筆記，每個重要觀念都必須有足夠的白話說明、具體例子及必要圖解。
- 採用「先理解觀念 → 學會公式 → 看懂例題 → 跟著逐步計算 → 自己練習 → 訂正錯誤 → 再次挑戰」的教學順序。
- 不要假設學生已經具備所有先備知識，遇到較難的數學概念，先補充理解該概念所必需的國中基礎。
- 每個重要知識點都盡量安排簡單的理解檢查題，確認學生真正學會。
- 每一步計算都必須清楚解釋數學依據，例如為什麼可以移項、約分、取對數、平方或代入公式。
- 整理公式時必須清楚說明限制條件，例如分母不得為零、根號內的定義域、對數的真數與底數限制等，依實際章節適用。
- 特別強化題目關鍵字、隱藏條件、解題方向與常見陷阱的判斷。
- 老師上課提到的特殊技巧、速解法、口訣與考試提醒，應優先整理。
- 遇到同一題有不同解法，可比較標準解法與老師速解法，說明各自適用時機。
- 所有公式、數學符號、正負號、指數、根號、分數、單位、計算過程及最後答案都要仔細驗證。
- 不清楚或無法辨識的教材內容，不得自行猜測為正確答案。
- 自行新增的教學例題及模擬題必須明確標示，不得冒充老師原題。
