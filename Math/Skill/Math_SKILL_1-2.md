# 高中數學段考備考 Skill｜精簡版

## 核心原則
**學舊考卷的「出題方式」，不學舊考卷的「考試範圍」。** 下次考點只能依新範圍、課本、講義、小考及老師逐字稿決定；沒有資料不猜必考內容。

## 1. 參考本次命題風格
- **題型**：單選 6 題、多選 4 題、填充 10 題（僅作模擬預設，依下一次公告調整）。
- **常見考法**：定義判斷、條件限制、反向推理、多步計算、選項真假與反例、文字情境轉算式。
- **出題設計**：把常見錯法做成干擾選項；改條件、改問法、設邊界陷阱，不只換數字。
- **關鍵能力**：單選要懂原因；多選逐項判定；填充不靠選項提示，能獨立推導與驗算。

## 2. 下次提供資料
新段考範圍、課本／講義、老師上課逐字稿、黑板筆記、小考／作業、老師提醒。先找**反覆出現、特別強調、易錯及需要多步推導**的考點；標明資料來源，將「老師明說」與「合理推測」分開。

## 3. 每個新考點的整理格式
1. **一句白話觀念**：為什麼這樣算？
2. **題目辨識**：看到哪些條件，想到什麼方法？何時不能用？
3. **解題 SOP**：已知 → 所求 → 列式 → 分步計算 → 驗算。
4. **三類例題**：基本題、老師風格標準題、改條件／改問法變化題。
5. **常見陷阱**：錯在哪、如何避免；多選每個選項皆說明對錯與反例。

## 4. 模擬卷與補強
- 依**新教材範圍**產生單選、多選、填充混合題；優先參考本次 6／4／10 配比，再依新證據調整。
- 題目分基本、標準、變化三層；高優先考點要包含**無選項填充**與**同觀念不同問法**。
- 每題附完整題目、正解、逐步詳解、錯誤原因及驗算。錯題依「讀題、觀念、列式、運算、驗算」分類再練。
- 先教會解題，再測驗；**不得只靠背題目或答案**。

## 5. 最終交付
製作**單一可離線 HTML 一頁式網頁**，順序為：
**考前核心觀念 → 解題 SOP／示範 → 分題型練習 → 模擬卷 → 錯題重練**。

互動：每題可獨立顯示提示與詳解、勾選已學會及答對、篩選錯題；**只顯示「答對 X／Y 題」**，不換算分數；**所有文字不要刪除線**。手機版易讀，公式與答案須逐題檢查。

## 使用指令
> 請參考這份 Skill 與 `Math/Prompt.md`，分析我提供的下次段考教材。只套用第一次段考的**題型、命題手法、思考深度與陷阱設計**，不要沿用上次章節。先教新範圍核心觀念與解題 SOP，再出老師風格的單選、多選、填充及變化題；每題附詳解，最後製作可離線的一頁式互動 HTML。
