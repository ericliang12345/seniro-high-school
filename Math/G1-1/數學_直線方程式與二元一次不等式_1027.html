02 / FORMULAS

四個公式與三個關鍵判斷

老師反覆提醒

兩點求斜率

m = (y₂ − y₁) / (x₂ − x₁)

「上面 y 差，下面 x 差」，相減時順序要一致。

老師反覆提醒

點斜式

y − y₀ = m(x − x₀)

已知過一點、又知道斜率，直接套用。

考卷第三大題

斜截式

y = mx + b

m 是斜率，b 是 y 軸截距（x = 0 時的 y 值）。

考卷第三大題

截距與面積

面積 = |a × b| / 2

a、b 分別是 x 截距與 y 截距。算長度時要取絕對值。

斜率正、負、零：用圖記最快

正斜率負斜率水平斜率 0

特殊狀況與易錯觀念

圖形斜率原因
右上正數y 增加
右下負數y 減少
水平線0y 差為 0
鉛直線不存在x 差為 0，不能除以 0
最常失分：鉛直線的斜率不是 0；「負斜率越陡」數值反而越小，例如 −3 < −1。

第一大題 第 3 題｜錄音檢討

題型 1：斜率比較

老師要求先計算各條直線的斜率，再比較大小；原考題各點座標未包含在摘要中。

補充完整練習題（非原考題）

已知直線 L₁ 經過 A(0, 1)、B(2, 5)，直線 L₂ 經過 C(1, 4)、D(3, 1)，直線 L₃ 經過 E(−2, 3)、F(2, 3)。請求三條直線的斜率，並由大到小排列。

展開逐步詳解
1
L₁：m₁ = (5 − 1) / (2 − 0) = 2
2
L₂：m₂ = (1 − 4) / (3 − 1) = −3/2
3
L₃：m₃ = (3 − 3) / [2 − (−2)] = 0
由大到小：m₁ > m₃ > m₂（2 > 0 > −3/2）

技巧：正數一定比 0 大；0 一定比負數大。

第一大題 第 1 題｜錄音答案 k = 2/3

題型 2：三點共線求 k

老師強調：三點共線時，可以令 mAB = mBC。原題三點座標未提供，無法還原其實際計算式。

補充完整練習題（非原考題）

在座標平面上，A(0, 0)、B(3, 2)、C(6, 3k + 2) 三點共線，求 k。

展開逐步詳解
1
mAB = (2 − 0) / (3 − 0) = 2/3
2
mBC = [(3k + 2) − 2] / (6 − 3) = 3k / 3 = k
3
共線 ⇒ 2/3 = k。
k = 2/3

這題是為了示範老師的方法自行編寫，答案恰好與錄音所述結果相同，不代表與原考題相同。

第三大題 第 3 題

題型 3：知道斜率和過點，求 a、b

依錄音資訊重述

已知直線 y = ax + b 通過點 (2, 3)，且斜率為 3，求數對 (a, b) 與直線方程式。

展開逐步詳解
1
y = ax + b 的斜率就是 a，所以 a = 3。
2
代入點 (2,3)：3 = 3 × 2 + b。
3
3 = 6 + b，移項得 b = −3。
(a, b) = (3, −3)；直線為 y = 3x − 3
第三大題 第 1 題

題型 4：直線和兩軸圍成的三角形面積

依錄音條件重述

某直線與 x 軸交於 (3, 0)，與 y 軸交於 (0, 4)。求此直線與 x、y 兩軸所圍成三角形的面積。

摘要提供的是兩個截距與答案，沒有完整原方程式。依截距可寫成 x/3 + y/4 = 1 作為圖解。

展開逐步詳解
1
與 x 軸交點的 y = 0，因此底長 = |3| = 3。
2
與 y 軸交點的 x = 0，因此高長 = |4| = 4。
3
面積 = 1/2 × 3 × 4。
面積 = 6 平方單位

補充：若題目改為直線方程式，先令 y = 0 找 x 截距，再令 x = 0 找 y 截距。

第三大題 第 4 題

題型 5：兩軸截距相等，求直線方程式

依錄音條件重述

有一直線通過點 (2, 3)，且它的 x 截距與 y 截距相等且不為 0。求此直線的方程式。

核心思考：截距一樣都設為 a，就能找出斜率 −1；再用點斜式。
展開逐步詳解
1
設兩個截距都為 a（a ≠ 0），交點為 (a, 0)、(0, a)。
2
m = (a − 0) / (0 − a) = −1。
3
過點 (2,3)，用點斜式：y − 3 = −1(x − 2)。
4
y − 3 = −x + 2 ⇒ y = −x + 5。
x + y = 5（或 x + y − 5 = 0）

驗算：令 y = 0，x = 5；令 x = 0，y = 5，兩截距的確相等。

別直接寫斜率 1！「兩個截距相等」不代表直線向上，而是截距點 (a,0) 與 (0,a) 連成斜率 −1 的直線。

主題六｜二元一次不等式（講義第 87～89 頁）

3 張講義｜4 組原題｜6 張正確解區圖

資料來源區分：上一章的斜率與直線方程式來自本週兩份錄音摘要；本章二元一次不等式是依你這次補上的講義第 87～89 頁整理。講義手寫的截距與測試點會保留對照，但解區圖由不等式重新計算繪製，確保實線、虛線和陰影一致。

本章完整重述例題 15、演練 15、例題 16、演練 16。圖片裁切保留該題題號、所有子題、手寫圖與計算區，章末亦附三頁完整照片供檢查。

一元一次式 → 直線；二元一次不等式 → 半平面

先畫 ax + by + c = 0 的分界線，再判斷線的哪一邊符合不等式。

ax + by + c > 0、< 0、≥ 0、≤ 0
符號邊界線口訣
>、<虛線不含等號，不含線上點
≥、≤實線有等號，包含線上點
注意：不等式不只是一條線，還要畫出符合條件的整片區域。

老師手寫圖的 4 步作答順序

  1. 變等號：畫出 ax + by + c = 0。
  2. 找截距：令 x=0 求 y 截距；令 y=0 求 x 截距。
  3. 代測試點：通常用 (0,0)，判斷在哪一邊。
  4. 決定線型、畫陰影：有等號實線；無等號虛線。聯立題只留下共同符合的區域。

如果分界線剛好通過 (0,0)，就要改選其他不在邊界線上的點（例如 (1,0) 或 (0,1)）。

EXAMPLE 15 · TEXTBOOK P.88

例題 15｜畫一條邊界線，判斷哪一邊

講義原題：圖示下列二元一次不等式的解：
(1) 3x − 2y + 6 > 0。
(2) x + 2y + 4 ≤ 0。

(1) 3x − 2y + 6 > 0

展開逐步詳解與驗算
1
畫邊界：3x − 2y + 6 = 0。令 y=0 得 (−2,0)；令 x=0 得 (0,3)。
2
代入原點：3×0 − 2×0 + 6 = 6 > 0，所以原點所在側是解區。
3
移項驗算：y < (3/2)x + 3，即直線下方；因只有 > 沒有等號，畫虛線。
解區：y < (3/2)x + 3；不含邊界，包含 (0,0)。

(2) x + 2y + 4 ≤ 0

展開逐步詳解與驗算
1
畫邊界：x + 2y + 4 = 0。x 截距 (−4,0)，y 截距 (0,−2)。
2
代入原點：0 + 2×0 + 4 = 4，不符合 4 ≤ 0，因此陰影畫在不含原點的一側。
3
移項得 y ≤ −(1/2)x − 2，位於直線下方。因有 ≤，畫實線。
解區：y ≤ −(1/2)x − 2；含邊界，不含 (0,0)。
EXERCISE 15 · TEXTBOOK P.88

演練 15｜自己判斷虛線、實線和原點

講義原題：圖示下列二元一次不等式的解：
(1) 2x − y − 6 ≥ 0。
(2) 2x + y − 2 < 0。

(1) 2x − y − 6 ≥ 0

展開逐步詳解與驗算
1
先畫 2x − y − 6 = 0：x 截距 (3,0)；y 截距 (0,−6)。
2
測試原點：2×0 − 0 − 6 = −6 < 0，不符合 ≥ 0。
3
改寫 y ≤ 2x − 6；陰影在線下，因有等號畫實線。
解區：y ≤ 2x − 6；包含 (3,0)、(0,−6) 等邊界點。

(2) 2x + y − 2 < 0

展開逐步詳解與驗算
1
先畫 2x + y − 2 = 0：x 截距 (1,0)；y 截距 (0,2)。
2
測試原點：0 + 0 − 2 = −2 < 0，符合原式，所以選原點那一邊。
3
改寫 y < −2x + 2；因沒有等號畫虛線。
解區：y < −2x + 2；不含分界線。
EXAMPLE 16 · TEXTBOOK P.89

例題 16｜聯立不等式：留下兩片陰影的交集

講義原題：圖示下列二元一次聯立不等式的解：
① x + y − 3 ≤ 0
② x − 2y + 4 ≥ 0
展開逐步詳解與驗算
1
第一條：x + y − 3 ≤ 0，即 y ≤ 3 − x；邊界經過 (3,0)、(0,3)；測原點 −3 ≤ 0，故取原點側。
2
第二條：x − 2y + 4 ≥ 0，即 y ≤ (1/2)x + 2；邊界經過 (−4,0)、(0,2)；測原點 4 ≥ 0，故也取原點側。
3
兩條線交點：令 3 − x = (1/2)x + 2，得 x=2/3、y=7/3。
4
兩題都要成立，兩條線下方的共同區域才保留；因 ≤、≥ 都有等號，兩條線均為實線。
解區：y ≤ 3 − x 且 y ≤ x/2 + 2；包含 (0,0) 與兩條邊界中符合另一條條件的部分。
EXERCISE 16 · TEXTBOOK P.89

演練 16｜一條實線、一條虛線

講義原題：圖示下列二元一次聯立不等式的解：
① 2x − 3y + 6 ≥ 0
② x + y − 2 > 0
展開逐步詳解與驗算
1
第一條：2x − 3y + 6 ≥ 0，移項時注意除以 −3 要變號，得 y ≤ (2/3)x + 2。直線經過 (−3,0)、(0,2)，畫實線。
2
第二條：x + y − 2 > 0，即 y > 2 − x，邊界經過 (2,0)、(0,2)，畫虛線。
3
第一條在直線下方；第二條在直線上方。交集就是兩條線中間、從 (0,2) 往右張開的區域。
4
試點 (2,2)：2×2−3×2+6=4 ≥ 0；2+2−2=2 > 0，故符合。(0,2) 則讓第二條等於 0，不符合嚴格大於。
解區：2 − x < y ≤ (2/3)x + 2；只有 x > 0 時存在解，交點 (0,2) 不包含。

04 / SCORE-SAVING RULES

老師提醒的失分陷阱

① 斜率順序不能亂

先選定「第二點減第一點」，分子分母都照做。

(y₂ − y₁) / (x₂ − x₁)

不可分子用 2−1，分母卻用 1−2。

② 數對有先後順序

答案是 (a, b) = (3, −3)，不能寫成 (−3, 3)。

老師說坐標題只要一個分量錯，就可能整題不給分。

③ 多選不能亂猜

多選或少選都有可能扣分，先把每個選項的斜率算清楚。

計算題則記得寫出推導過程，不只寫最後數字。
