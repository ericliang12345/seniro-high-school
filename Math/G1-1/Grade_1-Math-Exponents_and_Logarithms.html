老師口訣總整理：考前直接背這一區

把這堂課散落在黑板與口語中的技巧集中在一起。看到題目時，先找對應的「一句話」。
① 對數就是問：「指數是多少？」
看到 log 不要怕，先翻回 ab=c。
② 真數「乘 → 加、除 → 減、次方 → 搬前面」
對數展開最常用的三個動作。
③ 底數也有次方：上面 k、下面 t
logaᵗ(Pᵏ) = (k/t)logaP。
④ 先尾數，再首數
負對數尤其重要；尾數先整理成 0～1 之間。
⑤ 首數管位置，尾數管長相
這一句是整章最核心的總口訣。
⑥ 大於 1 問幾位：首數 + 1
例如 log x=47.71 → 48 位。
⑦ 小於 1 問第幾位非零：首數變號
例如首數 −85 → 小數點後第 85 位開始非零。
⑧ 問最高位數字：看尾數夾在哪兩個 log 整數中
0.71 在 log5 與 log6 間 → 首位 5。
⑨ 尾數相同：數字長相相同，只差 10 的整數次方
兩數相除一定是 10n。
⑩ 比較「幾倍」：用相除；同底數相除就指數相減
地震能量題最典型：107.5/106=101.5。
⑪ 複利題先畫時間軸：每過一年就 ×(1+r)
不同時間的錢不能直接加減，要先搬到同一個時間點。
⑫ 每期固定還款：搬到同一時點後，會長成等比級數
「一邊借、一邊還」最後就是借款終值 = 還款終值。
考場順序：先看題目問什麼 → 找口訣 → 再算。 不要一看到 log 就開始亂展開。
1

指數 ↔ 對數：其實是同一件事

老師的核心觀念：「對數就是對應的指數，一體兩面。」
ab = c ⇔ loga c = b
底數
a 保持不動
真數
c 是指數式的結果
答案
b 就是你在問的指數

成立條件：a > 0、a ≠ 1、c > 0。

例：23 = 8

log2 8 = 3

意思不是「log 很神秘」，只是問：2 的幾次方會變 8？答案 3。

例：log10 5 ≈ 0.699

100.699 ≈ 5

所以「log 5 = 0.699」等價於「10 的 0.699 次方約等於 5」。

2

對數運算：只背 3 句

黑板反覆使用的就是這三個規則。
口訣 1

真數相乘 → 對數相加

loga(PQ)
= logaP + logaQ
口訣 2

真數相除 → 對數相減

loga(P/Q)
= logaP − logaQ
口訣 3

真數有次方 → 指數搬前面

loga(Pk)
= k logaP

底數也有次方怎麼辦？

logat(Pk) = (k/t) logaP

記成：「真數次方 k 在上、底數次方 t 在下」。

兩個超常用的小變形

loga(1/P) = −logaP
log1/aP = −logaP

看到倒數，常常就是「多一個負號」。

3

首數與尾數：這堂課真正的主角

先用科學記號拆開，你就會知道它們各自在管什麼。
x = A × 10n, 1 ≤ A < 10
⇒ log x = n + log A
首數 n：管「10 的幾次方」 → 小數點放哪裡。
尾數 log A：管「A 長什麼樣」 → 首位數是幾。
正的對數

log x = 2.314

2.314 = 2 + 0.314

首數 = 2，尾數 = 0.314。

所以 x 是「2 點多 × 102」的量級，會是 3 位數。

最容易錯

log x = −2.314

−2.314 = −3 + 0.686

首數 = −3，尾數 = 0.686。

老師口訣：先找尾數，再找首數。 尾數要整理成 0～1 之間的非負小數。
⚠️
逐字稿口語中的「尾數一定是正數」，考試實作可記成：尾數取 0 ≤ m < 1；若剛好是 10 的整數次方，尾數可以是 0。

段考三大必考：一眼就知道怎麼做

老師在逐字稿後半段一直重複這三種問法。
題型 ①
問「幾位數？」

x > 1 時：位數 = 首數 + 1

老師黑板例題，重新整理成「三步解法」

把上課思路縮短成考場可直接使用的版本。
例題 A

3100：幾位數？首位數？

  1. log x = 100 log3 = 47.71
  2. 首數 47 → 48 位數
  3. 尾數 0.71，介於 log5 = 0.699 與 log6 = 0.7782
答案：48 位，首位數 5
例題 B

(1/7)100：第幾位開始非零？

  1. log x = −100 log7 = −84.51
  2. 整理：−84.51 = −85 + 0.49
  3. 首數 −85；尾數 0.49 介於 log3 與 log4
第 85 位開始非零，第一個有效數字是 3
例題 C

收訊強度：B 區是 C 區 10000 倍

已知 R(k)=2+5log k，C 區強度 5.2。

  1. B 區點數 = 10000k
  2. R(10000k)=2+5[log10000+logk]
  3. log10000=4，所以強度比原本多 5×4=20
B 區強度 = 5.2 + 20 = 25.2
延伸觀念

尾數相同代表什麼？

尾數相同 = 長相相同

例如 2.34、23.4、234、0.0234，科學記號的有效數字部分都一樣，只是小數點位置不同。

因此兩數相除 = 10 的整數次方
a/b = 10n, n ∈ Z
內插法

老師的比喻：「捲髮剪得夠短，就看起來像直線」

當兩個已知點非常接近時，曲線的小段可以近似當成直線，用比例估計中間值。考試若要求更精準的首位或有效數字，這就是查表／內插的概念。

新增兩個老師應用例題

複利貸款＋地震能量。這兩題最重要的不是計算量，而是「把文字翻成指數式，再利用對數處理」。
新增例題 1｜複利貸款

借 300 萬、年利率 2%，20 年每年還相同金額 x

老師的想法：「把它當成兩個戶頭：一個借錢、一個還錢。」
  1. 借款 300 萬放 20 年：300(1.02)20。
  2. 第 1 年還的 x 到第 20 年會變成 x(1.02)19；第 2 年還的變成 x(1.02)18；…；第 20 年還的就是 x。
  3. 把所有錢都「搬到第 20 年」：
    x[1+1.02+(1.02)2+…+(1.02)19] = 300(1.02)20
  4. 等比和：
    S = [(1.02)20−1]/(1.02−1)
  5. 利用 log1.02≈0.0086：
    log(1.0220) = 20×0.0086 = 0.172
    所以 (1.02)20≈1.486。
  6. S≈(1.486−1)/0.02=24.3。
  7. x≈300×1.486/24.3≈18.35 萬。
每年約還 18.35 萬元 ≈ 18 萬 3 千多元（依老師板書近似值）。
逐字稿有幾處把「20」辨識成「24」。這裡依黑板時間軸 0→20、級數到 (1.02)19，整理為 20 年／20 期。
展開：老師上課逐字稿（整理版）

老師：某年初跟銀行借 300 萬，年利率 2%，一年後如果沒有還，會變成 300×1.02。再過一年，就再乘一次 1.02；所以到第 20 年，借款這邊會變成 300×(1.02)20。

老師：現在看你怎麼還錢。可以把它想成兩個戶頭：一個是借錢，一個是還錢。第一年還 x 元，這筆錢到第 20 年等於 x×(1.02)19；第二年還的 x，會變成 x×(1.02)18；一直到最後一期就是 x。

老師：所以黃色要等於綠色，也就是「這筆借款最後的錢 = 這一坨每期還款累積的錢」。不是把 300 萬直接除以 20，因為有利息。

老師：x 的係數形成等比總和：1+r+r²+…+r19。如果設這串叫 S，把 S 乘 r，再上下相減，就得到 S=(r20−1)/(r−1)。

老師：r=1.02，而 log1.02=0.0086，所以 20log1.02=0.172，查表得到 (1.02)20 約 1.486。等比和約 24.3，最後再把 300×1.486 除以 24.3，就得到每一期大約要還 18.3 萬。

這題口訣：「先畫時間軸，把所有錢搬到同一個時間點；固定還款搬完後就是等比級數。」

新增例題 2｜地震能量

7.3 級地震，相當於 5.8 級地震的幾倍能量？

老師的第一步：「先把符號弄清楚；要找幾顆原子彈，就是找能量倍數。」

題目給：

log I = r + 0.2

所以先轉成指數式：

I = 10r+0.2
  1. 5.8 級： I₀=105.8+0.2=106，題目把它當作 1 顆原子彈能量。
  2. 7.3 級： I=107.3+0.2=107.5。
  3. 問「幾倍」就相除：
    I/I₀ = 107.5/106 = 101.5
  4. 101.5=10√10≈31.6。
約 32 倍，也就是約 32 顆原子彈的能量。
逐字稿中間出現 0.75、1.3 等辨識／口語混亂；依黑板最後式子，倍率為 101.5，所以約 31.6 ≈ 32。
展開：老師上課逐字稿（整理版）

老師：第一件事情先把符號弄清楚。I 代表能量，r 代表地震規模。題目告訴你 log I = r+0.2，寫成指數就是 I=10r+0.2。

老師：5.8 級地震的能量等於一顆原子彈。把 5.8 代進去，就是 106。現在 7.3 級代進去，能量是 107.5。

老師：要問「大概是幾顆原子彈」，就是求倍數，所以兩個能量相除。107.5 除以 106，指數相減，得到 101.5。

老師：101.5 = 10×100.5 = 10√10。√10 大約 3.1 多，所以大約 31～32，答案約 32 顆。

這題口訣：「比較幾倍就相除；同底數相除，指數直接相減。」

最容易失分的 5 個坑

考前看這段最省分。
① 負對數直接把「−2.314」拆成 −2 和 −0.314

錯。尾數要整理成 0～1：−2.314 = −3 + 0.686。

② 位數看尾數

錯。位數看首數；尾數是看首位數／有效數字長相。

③ log(PQ) = logP × logQ

錯。真數乘法進 log 後變加法。

④ log(P+Q) 可以拆

不可以。只有乘、除、次方有標準拆法；加減不能直接拆。

⑤ 小數第幾位非零算錯一格

例如 0.00345 = 3.45×10−3，所以第 3 位開始非零。

考場總口訣

先尾數、再首數；首數管位置、尾數管長相。
