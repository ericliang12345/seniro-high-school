① 多項式除法原理：先記住一個骨架

和國小整數除法一樣，例如 17 ÷ 5 = 3 餘 2，所以 17 = 5 × 3 + 2。多項式也遵守同一個規則。

f(x) = g(x) × q(x) + r(x)
f(x) 被除式
原本要拿去除的式子
g(x) 除式
拿來除的式子
q(x) 商式
除出來的結果
r(x) 餘式
最後剩下的部分

餘式的次數有限制

餘式 = 0，或 deg(r) < deg(g)
除式餘式最多長怎樣？
一次式 x − 2常數 r
二次式 x² + 1ax + b
三次式 x³ − 2ax² + bx + c

注意：「最多」表示可以有係數為 0 的情形，例如二次除式的餘式也可能只是常數或 0。

② 餘式定理：為什麼代入就有答案？

當 f(x) 除以 x − a：

f(x) = (x − a)q(x) + r

令 x = a，因為 a − a = 0，整個乘積消失：

f(a) = 0 × q(a) + r = r
一秒記法：除以 x − a，就代入 a；除以 x + 3，就代入 −3。

③ 綜合除法：符號最容易出錯

除以 x − 2，綜合除法左側填 2；除以 x + 2，填 −2。因為要找讓除式等於 0 的 x。

補充示範：f(x) = x² + 3x + 2，除以 x − 2

  1. 寫係數：1、3、2。
  2. 左邊填 2；第一個係數 1 直接放下來。
  3. 1 × 2 = 2；3 + 2 = 5。
  4. 5 × 2 = 10；2 + 10 = 12。
  5. 得到商式 x + 5、餘式 12。驗算：f(2) = 4 + 6 + 2 = 12。
老師提醒：如果除式是 2x − 1，先用 x − 1/2 做綜合除法求得商式，再把該商式除以 2；餘式不變。

④ 常見變化題：段考很愛考

題型 A｜除式乘倍數，商和餘式怎麼變？

假設 f(x) = (x − a)q(x) + r。當除式改為 m(x − a)（m ≠ 0）：

f(x) = [m(x − a)] × [q(x)/m] + r

結論：除式乘 m，商式除以 m，餘式不變。

題型 B｜二次除式要設一次餘式

如果題目要找 f(x) 除以 (x − 1)(x − 2) 的餘式，先設 r(x) = ax + b。

假設題目另外給 f(1) = 3、f(2) = 5，那麼：

a + b = 3，2a + b = 5

相減得 a = 2，代回得 b = 1，所以餘式為 2x + 1。

這是為了理解課堂技巧而補充的示範數字，不是老師原題。若除式無法分解成相異一次因式，則需要其他條件或方法。

題型 C｜高次函數值與根號代入

求 f(13) 等同於求 f(x) 除以 x − 13 的餘式；求 f(1 + √2) 等同於求 f(x) 除以 x − (1 + √2) 的餘式。

補充提醒：改用除法不一定比較快。尤其根號題可先利用滿足的二次關係化簡，視題目結構選擇方法。

⑤ 分步例題（依課堂觀念補充）

例 1｜f(x) = 2x³ − x + 4，除以 x − 2 的餘式？

第一步：除以 x − 2，所以代入 2。

第二步：f(2) = 2(2³) − 2 + 4 = 16 − 2 + 4。

答案：18。

例 2｜f(x) = 2x² + 3x + 1，除以 2x − 1 的商、餘式？

先看 2x − 1 = 0，得 x = 1/2。

餘式 = f(1/2) = 2(1/4) + 3/2 + 1 = 3。

先除以 x − 1/2，可得商 2x + 4、餘式 3；原除式是它的 2 倍，所以商除以 2。

答案：商 x + 2，餘式 3。 驗算：(2x − 1)(x + 2) + 3 = 2x² + 3x + 1。

例 3｜已知 f(1) = 4、f(3) = 10，除以 (x − 1)(x − 3) 的餘式？

二次除式，設餘式 ax + b。

x = 1：a + b = 4。

x = 3：3a + b = 10。

兩式相減：2a = 6，a = 3；所以 b = 1。

答案：3x + 1。

⑥ 補充講義｜單元 5 直線方程式（例題 4～5）

教材分類提醒：這兩頁是「直線方程式」，不是「多項式除法與餘式定理」。依你的要求放在同一份 10/20 網頁，但獨立成章，避免混淆。

先懂三種直線方程式

點斜式
y − y₀ = m(x − x₀)
知道斜率 m 和直線上一點 (x₀,y₀) 時使用。
斜截式
y = mx + b
m 是斜率；b 是 y 截距（通過 (0,b)）。
截距式
x/a + y/b = 1
通過 (a,0)、(0,b)；a、b 都不能為 0。

已知一般式，怎麼找斜率？

Ax + By + C = 0 → m = −A/B（B ≠ 0）

也可以把 y 單獨移到左邊，整理成 y = mx + b，x 前面的係數就是斜率。

考前口訣：「給斜率和點 → 點斜式；給兩個截距 → 截距式；問斜率 → 整理成 y = mx + b。」
特例：水平線斜率 0；鉛直線斜率不存在。

⑦ 講義例題與演練｜完整逐題解法

以下依你上傳的兩張講義照片整理，保留原題與正確計算。點擊每題可展開步驟。

例題 4（1）｜斜率 3、y 截距 −4，求直線方程式
  1. 斜率 m = 3，y 截距 −4，代表直線經過 (0,−4)。
  2. 用斜截式 y = mx + b：y = 3x − 4。
  3. 若寫成一般式：3x − y − 4 = 0（或 −3x + y + 4 = 0）。

答案：y = 3x − 4。

例題 4（2）｜x 截距 −2、y 截距 3，求直線方程式
  1. 截距表示通過 (−2,0)、(0,3)。
  2. 套截距式：x/(−2) + y/3 = 1。
  3. 兩邊乘 6：−3x + 2y = 6。
  4. 移項：3x − 2y + 6 = 0。

答案：3x − 2y + 6 = 0。

演練 4（1）｜斜率 2/3、y 截距 0，求直線方程式
  1. 直線通過原點 (0,0)。
  2. y = (2/3)x + 0。
  3. 乘 3：3y = 2x。

答案：2x − 3y = 0。

演練 4（2）｜x 截距 3、y 截距 −1，求直線方程式
  1. 通過 (3,0) 與 (0,−1)。
  2. 截距式 x/3 + y/(−1) = 1，即 x/3 − y = 1。
  3. 乘 3：x − 3y = 3。

答案：x − 3y − 3 = 0（等價寫法 −x + 3y + 3 = 0）。

例題 5（1）｜3x + 2y − 5 = 0，求斜率

移項：2y = −3x + 5 → y = −(3/2)x + 5/2。

答案：m = −3/2。

例題 5（2）｜(1/2)x + (1/4)y = 1，求斜率

兩邊乘 4：2x + y = 4 → y = −2x + 4。

答案：m = −2。

演練 5｜選出斜率最小的直線（四選一）

逐一整理成 y = mx + b：

選項原題整理後斜率
(1)2x + y + 1 = 0y = −2x − 1−2
(2)3x − 4y + 5 = 0y = (3/4)x + 5/43/4
(3)y − 3 = 8(x + 1)y = 8x + 118
(4)(1/2)x + (1/3)y = 1y = −(3/2)x + 3−3/2

由小到大：−2 < −3/2 < 3/4 < 8。

答案：（1）。負數越負越小，不是看絕對值。
