圓方程式：抓住圓心與半徑

圓的定義：所有到圓心距離都一樣的點，連起來就是圓。

(x − h)² + (y − k)² = r²

圓心 (h,k)；半徑 r。注意括號裡的符號與圓心座標相反。

(x − 2)² + (y − 1)² = 9

一般式：看到它，先配方

x² + y² + dx + ey + f = 0
圓心
(−d/2, −e/2)
判別量 Δ
Δ = d² + e² − 4f
半徑
r = √Δ / 2
Δ代表想像
Δ > 0一個真正的圓半徑大於 0
Δ = 0一個點半徑等於 0
Δ < 0沒有實數圖形半徑平方不可能為負
老師提醒：段考通常不附判別式公式。更重要的是會「配方法」，理解右邊就是半徑平方。

課本例題 6：參數 k 決定圓、點、還是沒有圖形

題目：x² + y² + 4x − 2ky + k² + k = 0

把 x、y 分別配方。

得到 (x+2)² + (y−k)² = 4−k。

右邊就是 r² = 4−k，看正、零、負即可。

k = 2，r² = 2，圖形是一個圓
考試答案：k < 4 是圓；k = 4 是點，座標 (−2,4)；k > 4 沒有圖形。

課本演練 6：已知半徑 2，反求 k

x² + y² + 2kx − 6y + 4k + 1 = 0

點我看一步一步解法

圓心由係數看出是 (−k,3)。

r² = k² + 9 − 4k − 1 = k² − 4k + 8。

半徑 2，所以 r² = 4，得 k² − 4k + 4 = 0。

(k−2)² = 0，所以 k = 2，圓心 (−2,3)。

阿波羅尼斯圓：兩個固定點，距離保持固定比例

想像 A、B 是兩間店，P 是你的位置。若 P 到 A 的距離永遠是到 B 的一半，P 可以走出的軌跡會是一個圓。

PA / PB = t（t > 0）
t = 1

一樣遠 → AB 的中垂線

t ≠ 1

固定不同距離比 → 阿波羅尼斯圓

課本例題 7：A(0,0)、B(12,0)

圓心 (−4,0)，半徑 8

① PA = ½ PB，為什麼是 (x+4)² + y² = 64？

PA = √(x²+y²)，PB = √((x−12)²+y²)。

兩邊平方：4(x²+y²) = (x−12)²+y²。

整理：3x²+3y²+24x−144=0。

除以 3、配方：(x+4)²+y²=64。

② PA = PB，為什麼變成直線？

x²+y² = (x−12)²+y² → 24x = 144 → x = 6，就是 A、B 正中間的鉛直線。

課本演練 7：A(5,3)、B(4,−1)，2PA = 3PB

看答案與過程

4[(x−5)²+(y−3)²] = 9[(x−4)²+(y+1)²]

整理得 5x²+5y²−32x+42y+17=0。

配方：(x−16/5)²+(y+21/5)² = 272/25。

圓心 (16/5,−21/5)，半徑 4√17/5。

課本例題 8：焚化廠選址，數學怎麼用在生活？

A(0,0)、B(20,0)，垃圾量 2 : 3。距離要和垃圾量成反比，所以 PA : PB = 3 : 2。

距離比例寫成 2PA = 3PB。

平方：4(x²+y²) = 9[(x−20)²+y²]。

配方得到 (x−36)²+y²=24²。

只允許在北方 y > 0；離 AB 直線最遠，就是圓的最上方。

最佳位置：P(36,24)，也就是 A 以東 36 公里、以北 24 公里。

注意：上半圓的兩個端點是圓與 x 軸的交點 (12,0)、(60,0)，不是 A、B；因 y > 0，兩端點不包含。
