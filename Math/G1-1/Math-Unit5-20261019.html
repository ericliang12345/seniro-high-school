高一數學｜直線方程式

主題一：直線的斜率 · 講義第 72–73 頁 · 觀念、圖解、原題詳解、互動測驗

核心觀念互動斜率公式與陷阱講義例題課後練習自我測驗段考提醒

① 先懂斜率是什麼

把直線想成一條山坡。往右走 1 格，往上或往下走幾格，就是斜率 m。

↗ 上坡：m > 0向右走，越走越高。例：右 1、上 3 → m = 3
↘ 下坡：m < 0向右走，越走越低。例：右 1、下 2 → m = −2
→ 平地：m = 0向右走，高度完全不變。
↑ 直立：斜率不存在鉛直線沒有「向右走 1 格」的情況。
一句話記住：斜率 = 高度變化 ÷ 水平變化 = y 的變化 ÷ x 的變化。

國中與高中怎麼接起來？

國中學過 y = ax + b，其中 a 就是斜率，b 是與 y 軸交點的 y 座標。本次先學會斜率，後續才接點斜式、斜截式。

② 拖動滑桿，看懂正、負、陡度

固定直線通過原點，調整斜率 m，觀察它如何旋轉。

m = 1.5

圖形為教學示意；鉛直線無法用有限數值的 m 表示，斜率「不存在」。

③ 兩點求斜率：必背公式

給兩點 A(x₁, y₁)、B(x₂, y₂)，而且 x₁ ≠ x₂：

m = (y₂ − y₁) / (x₂ − x₁)

口訣：上面減 y，下面減 x；上下順序要一致。

✓ 正確(y₂ − y₁) / (x₂ − x₁)
✓ 也正確(y₁ − y₂) / (x₁ − x₂)
✗ 常見錯誤(x₂ − x₁) / (y₂ − y₁)（顛倒了）

兩種特殊線，一定要分清楚

直線條件公式結果考試寫法
水平線y₁ = y₂，x₁ ≠ x₂0 ÷ 非 0m = 0
鉛直線x₁ = x₂，y₁ ≠ y₂非 0 ÷ 0斜率不存在
⚠️ 不存在 ≠ 0。斜率為 0 是水平線；斜率不存在是鉛直線。兩點若完全相同，也不能只靠這兩點決定唯一的直線。

斜率比大小：老師的分組法

先分成 正數 ＞ 0 ＞ 負數，再比陡度。上坡越陡，m 越大；下坡越陡，m 越負、數值越小（但 |m| 越大）。

3 ＞ 1 ＞ 0 ＞ −1 ＞ −3

④ 課本與講義原題詳解

說例｜A(1,2)、B(3,5)

① 找出 x₁=1、y₁=2、x₂=3、y₂=5
② m = (5 − 2) / (3 − 1)
③ m = 3/2（往右 2，上升 3）

例題 1｜四條線都經過 A(1,2)

講義標示的其餘點分別是：L₁ 經 (3,2)、L₂ 經 (3,3)、L₃ 經 (2,4)、L₄ 經 (0,4)。

直線代入計算答案判斷
L₁(2−2)/(3−1)0水平
L₂(3−2)/(3−1)1/2緩上坡
L₃(4−2)/(2−1)2陡上坡
L₄(4−2)/(0−1)−2下坡
關鍵：點 (0,4) 的 x 是 0，因此 L₄ 的分母是 −1，答案為 −2。

例題 2｜正五邊形的五條邊比斜率

依講義圖，正五邊形依序為 A → B → C → D → E → A，且 AB 平行 x 軸。分別對應 m₁、m₂、m₃、m₄、m₅。

點開看完整比較步驟
① 正斜率：BC（m₂）、DE（m₄）。BC 比 DE 更陡，所以 m₂ ＞ m₄。
② 零斜率：AB（m₁ = 0）。
③ 負斜率：CD（m₃）、EA（m₅）。EA 向右下降更陡，所以 m₅ 更負，m₃ ＞ m₅。
m₂ ＞ m₄ ＞ m₁ ＞ m₃ ＞ m₅

⑤ 講義演練 1｜三條線求斜率

原題：已知 A(−2,1)、B(3,1)、C(1,4)，求直線 AB、BC、AC 的斜率。先自己算，再展開。

AB 的斜率：顯示詳解

mAB = (1 − 1) / (3 − (−2)) = 0/5 = 0。因為兩點 y 相同，所以是水平線。

BC 的斜率：顯示詳解

mBC = (4 − 1) / (1 − 3) = 3/(−2) = −3/2。往右看是下坡。

AC 的斜率：顯示詳解

mAC = (4 − 1) / (1 − (−2)) = 3/3 = 1。注意減負數等於加正數。

三題答案：AB = 0；BC = −3/2；AC = 1。

考前 30 秒速背

① 斜率 = y 差 / x 差。
② 右上正、右下負、水平零、鉛直不存在。
③ 正斜率越陡越大；負斜率越陡越小。
④ 減法順序一致、負號小心、分數約分。
