① 先懂整章在學什麼

單元 6｜圓方程式

先找到圓心 M 和半徑 r，才能判斷點在哪裡、求距離、算面積。

(x−h)²+(y−k)²=r²

圓心 (h,k)，半徑 r

單元 7｜圓與直線

圓心到直線的距離 d，決定直線碰到圓幾次。

d＜r 相割｜d＝r 相切｜d＞r 相離

② 段考必背 6 個公式

1. 圓的標準式

(x−h)²+(y−k)²=r²

看括號反號找圓心，右邊開根號找半徑。

2. 配方法

x²+2ax=(x+a)²−a²

一次項係數「除以 2 再平方」，補成完整平方。

3. 兩點距離

AB=√[(x₂−x₁)²+(y₂−y₁)²]

本質就是畢氏定理。

4. 點到直線距離

d=|ax₀+by₀+c|/√(a²+b²)

直線要先整理成 ax+by+c=0。

5. 弦長

弦長=2√(r²−d²)

先算半條弦，再乘 2。

6. 判別式

Δ=B²−4AC

Δ＞0 兩點；＝0 一點；＜0 零點。

老師的快速解題流程

讀題 → 圈關鍵字 → 找圓心、半徑 → 畫簡圖 → 選方法 → 檢查答案。

問「交點座標」用聯立；問「有幾個交點」通常比 d 和 r；問「弦長」用畢氏定理；問「k 範圍」用等式或不等式。

題目 01

例題9｜判斷點在圓內、圓上、圓外

老師的解題思路與步驟
  1. 圓心 M(-3,2)，半徑 r=10
  2. P(5,-4)：MP=√(64+36)=10 → 圓上
  3. Q(6,0)：MQ=√85＜10 → 圓內
  4. R(4,10)：MR=√113＞10 → 圓外

💡 先找圓心、半徑，再比「點到圓心的距離」。

題目 02

演練9｜求 k 的範圍

老師的解題思路與步驟
  1. 圓心 M(1,2)，半徑平方為 k
  2. P(3,-1) 在圓內：MP²=4+9=13＜k
  3. Q(-3,3) 在圓外：MQ²=16+1=17＞k
  4. 答案：13＜k＜17

💡 比距離平方更快，不用開根號；k 是半徑平方，不是半徑。

題目 03

例題10｜最長、最短距離

老師的解題思路與步驟
  1. 配方：(x−1)²+(y−2)²=4
  2. 圓心 M(1,2)，r=2
  3. P(-2,-2) 到 M 的距離為 5
  4. 最大=5+2=7；最小=5−2=3

💡 連接 P 與圓心，延長線兩端就是最遠、最近位置。

題目 04

例題11｜莫耳圓與直徑端點

老師的解題思路與步驟
  1. 莫耳圓：圓心在 x 軸上，且半徑＞0
  2. 第(1)題：符合的是 ①、⑤（⑥ 的半徑平方為負）
  3. A(3,4)、B(7,-4) → 中點 M(5,0)
  4. 半徑平方=20 → (x−5)²+y²=20
  5. 三圓半徑 3、1、2；大圓扣兩小圓：9π−π−4π=4π

💡 直徑題先找中點；圓面積用 πr²。

題目 05

例題12｜圓弧提把的長度

老師的解題思路與步驟
  1. 以 A 為原點，P(-15,0)、Q(15,0)、B(0,5)
  2. 圓心在 y 軸，設 M(0,b)
  3. 代入 B、Q 得 (5−b)²=225+b² → b=−20
  4. 圓半徑 r=25；C(7,0) 的上方交點 D(7,y)
  5. 49+(y+20)²=625 → y=4（取上方）
  6. CD=4 公分

💡 生活應用題：先建立座標，再用「點在圓上」代入。

題目 06

例題1｜聯立求圓與直線交點

老師的解題思路與步驟
  1. C：x²+y²=10，L：x−y+2=0
  2. 由直線得 y=x+2
  3. 代入：x²+(x+2)²=10 → x²+2x−3=0
  4. x=1 或 −3 → 交點 (1,3)、(−3,−1)

💡 題目要交點座標 → 優先聯立代入。

題目 07

例題2｜相切求 k

老師的解題思路與步驟
  1. C：x²+y²+kx−2y+8=0；L：x−y=0
  2. 代入 y=x：2x²+(k−2)x+8=0
  3. 相切只有一個交點 → Δ=(k−2)²−64=0
  4. k=10 或 −6

💡 圓與直線相切 → 聯立後判別式 Δ=0。

題目 08

例題3｜用距離判斷相割、相切

老師的解題思路與步驟
  1. M(2,1)，r=4
  2. L₁：3x+4y+5=0 → d=|6+4+5|/5=3＜4 → 相割
  3. L₂：12x+5y+23=0 → d=|24+5+23|/13=4 → 相切

💡 只問關係 → 用圓心到直線距離最快。

題目 09

例題4｜求弦長 AB

老師的解題思路與步驟
  1. M(3,−2)，r=13
  2. L：4x−3y+7=0
  3. 圓心到直線距離 d=|12+6+7|/5=5
  4. 半弦長=√(13²−5²)=12
  5. AB=2×12=24

💡 弦長公式：2√(r²−d²)，來自畢氏定理。

題目 10

例題5｜相切與相割的 k

老師的解題思路與步驟
  1. M(3,−1)，r=2
  2. L：5x+12y+k=0 → d=|3+k|/13
  3. 相切：|k+3|/13=2 → k=23 或 −29
  4. 相割：|k+3|/13＜2 → −29＜k＜23

💡 遇到絕對值不等式，記得拆成左右兩邊。

④ 老師最在意的易錯點

  1. 半徑平方不是半徑：右邊 25，半徑是 5。
  2. 圓心要反號：(x+3)² 的圓心 x 座標是 −3。
  3. 配方要兩邊同加：不能只在左邊補平方。
  4. 真正的圓必須 r²＞0：等於 0 只有一個點。
  5. 相切只有一個交點：距離法 d=r；代數法 Δ=0。
  6. 弦長記得乘 2：畢氏定理先算的是半弦。
  7. 最短距離：點到圓周最短是 |MP−r|，不是永遠 MP−r。
