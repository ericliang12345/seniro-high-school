# 國文段考高分複習 Skill（精簡版）

## 目標
不只背課文，更要**看懂新題、找出原文證據、排除錯誤選項**。以上次 62 分為改善參考，下次以**多拿 15 分**為努力目標（非保證）。

**先讀取並套用：** [Chinese/Prompt.md](https://github.com/ericliang12345/seniro-high-school/blob/main/Chinese/Prompt.md)。其「完整原文、逐句翻譯、注釋、原卷、互動與離線 QA」規範繼續適用；本 Skill 只補充**命題分析與考前策略**。

## 輸入素材與用途
1. **國文課本：**核對課文、注釋、主旨、作者、修辭與考試範圍。
2. **小考考卷：**分析題型、常考觀念、干擾選項與學生錯題。
3. **上課錄音逐字稿：**擷取老師重複強調、解題口訣、易錯提醒、考試提示。

分批上傳時，等使用者說「傳完了／開始整理」才製作；不得臆測缺少的內容、答案或老師指示。

## 整理流程
**① 交叉比對：**以「課本內容＋小考題號＋老師提醒」建立考點表；無證據時標註未確認。

**② 排定優先級：**
- **A 必讀：**小考常考／學生答錯／老師反覆強調。
- **B 應懂：**核心字詞、逐句句意、主旨、修辭、作者作品。
- **C 延伸：**同主題陌生短文、詩句比較與推論練習；不得假稱必考。

**③ 每個重要考點：**白話教學 → 原文證據 → 老師提醒 → 常見陷阱 → 段考考法 → 變化題與逐選項詳解。

**④ 特別強化：**
- 字形、字義、成語的**語境判斷**。
- 詩文**字面／深層情感**與修辭效果。
- **跨文本比較**：雙方都要找原文依據。
- **陌生閱讀**：區分明說、合理推論、過度推論。
- **多選題**：每個選項獨立判斷，避免漏選與誤選。

## 一頁式 HTML 結構
1. **考前 3 分鐘**：最高優先考點與易錯口訣。
2. **考前 30 分鐘**：A／B 級重點、對照表與老師提醒。
3. **完整課文教學**：依主 Prompt 逐句翻譯；折疊顯示避免過長。
4. **小考原題練習**：完整題目、逐題提示、答案與解析。
5. **段考變化題**：建議 30% 基礎、70% 應用；包含反向題、跨篇、陌生閱讀、多選。
6. **錯題補強**：依失分原因分類，回顧觀念後再做新題。

**互動要求：**答案預設隱藏、各題獨立顯示詳解、有測驗與進度紀錄；單一 HTML、手機電腦可用、完全離線。**原題與 AI 新編題分開標示**；每個選項都解釋對錯原因。

## 完成前檢查
- 範圍、課文與老師重點無遺漏；逐句翻譯及原題圖文完整。
- 考點有來源；答案、詳解、圖片與題號正確配對。
- 已加入陷阱分析、陌生題、跨篇比較和多選題。
- 互動、計分、錯題重練及離線功能經測試；未測試須說明。
- 若發布 GitHub，依專案根目錄 `SKILL.md` 更新 README 索引；未經確認不得聲稱已推送。

## 啟動指令
> 使用 `chinese-exam-review` Skill，搭配 `Chinese/Prompt.md`，依這次提供的課本、小考與逐字稿，先分析老師命題方向，再製作「3 分鐘速讀＋30 分鐘必讀＋完整教學＋原題＋變化題＋錯題補強」的一頁式離線 HTML。
