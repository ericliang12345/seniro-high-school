網站請包含：

1. **課文完整教學與逐句翻譯**：依教材完整保留課文原文，按照原文的句號「。」逐句分段解說。每一句都提供「原文 → 白話翻譯 → 重要字詞 → 句意解析 → 考試重點」。若一句很長，可再依語意拆解，但不可省略原文。文言文必須解釋每一句的意思，讓原本看不懂古文的學生也能完全理解。

2. **文章背景與作者介紹**：整理作者姓名、字號、朝代、生平、文學地位、重要作品、寫作背景與相關文學流派，以教材實際範圍為主。特別說明作者為什麼寫這篇文章、當時的情境，以及背景如何影響文章主旨。

3. **文章結構與主旨分析**：整理每個段落的大意、文章發展脈絡、寫作目的、中心思想、情感轉折與結尾寓意。利用文章結構圖、段落流程圖及比較表，幫助學生理解「作者想表達什麼、為什麼這樣寫、前後段落有什麼關係」。

4. **重要字音、字形與字義**：完整整理教材與老師強調的重要生字、注音、解釋、古今異義、通假字、詞類活用、一字多義及常見成語。對容易混淆的字詞，使用比較表與例句教學，並標示常見考法及記憶技巧。

5. **文言文特殊句型與語法**：依教材內容整理倒裝句、省略句、判斷句、被動句、虛詞、實詞及重要文言語法。每個觀念提供原文例句、白話解釋、判斷方法與常見錯誤，教學生真正看懂古文，而不只是背翻譯。

6. **修辭技巧與寫作特色**：整理文章出現的重要修辭，例如譬喻、轉化、排比、對偶、誇飾、映襯、借代、設問等，依實際教材內容教學。每個修辭都要包含「定義 → 課文例句 → 白話說明 → 表達效果 → 段考考法」，並比較容易混淆的修辭。

7. **國學常識與文學比較**：整理教材涉及的文學體裁、詩詞格律、散文特色、文學流派、重要作家與作品。適合比較的內容使用表格，例如古體詩與近體詩、樂府詩與古詩、不同作家風格等，但僅納入教材實際涵蓋的內容。

8. **詩詞與古典文學賞析**：遇到古詩、樂府、近體詩、詞或曲，除了逐句翻譯，還要詳細解說詩句中的人物、情境、意象、情感、象徵、修辭及整首作品的主旨。特別說明詩句表面意思與深層含義，避免學生只背翻譯卻不懂作品。

9. **老師上課重點與段考方向**：整合老師上課強調的字詞、注釋、重要句子、修辭、文章主旨、國學常識、口訣及考試提醒。每個重要知識點都要說明「為什麼重要、老師特別提醒什麼、考試可能怎麼考、學生容易錯在哪裡」。

10. **逐段理解檢查與互動練習**：每個重要段落或知識點都安排適量理解題，包含字詞解釋、句意判斷、修辭辨識、文章理解與主旨分析。學生先自行思考，再按「看提示」取得方向，按「看答案」才顯示正確答案與詳細解說，確保學生真正理解。

11. **原卷互動練習**：將提供的老師例題、課本練習、測驗卷及考卷 PDF 完整納入網站，保留原始題目截圖，包括題幹、所有選項、閱讀文章、注釋、圖表及子題。每題可以獨立作答，按「看提示」顯示解題方向，按「看答案」才顯示正確答案與詳細解析。選擇題須說明正確選項為什麼對、其他選項為什麼錯，並連結到對應的課文與知識點。若提供原始詳解，也必須完整保留並正確配對，不要另外建立重複的文字版原卷題目。

12. **考前模擬測驗**：根據教材重點、老師提醒與原卷出題方向，另外設計適量的段考預測題，涵蓋字音字形、字詞解釋、文言文翻譯、句意理解、修辭、國學常識、文章主旨、比較分析及閱讀素養。難度由基礎到進階，並明確區分原卷題與新增模擬題。提供客觀題自動批改、分數統計、逐題詳解與錯題重練。

13. **錯題分析與弱點補強**：依學生答題結果，將錯誤分類為「字詞不熟、翻譯錯誤、文言語法不懂、修辭混淆、主旨理解錯誤、國學常識不足、閱讀推論失誤」。每道錯題連結回對應教學內容，提供補強說明與類似練習。

14. **考前快速總複習**：最後整理「必背字音字形、重要注釋、文言文翻譯、核心句子、作者與作品、文章主旨、修辭比較、國學常識、易錯觀念、常考題型及考前 3 分鐘重點」，方便學生快速回顧整個段考範圍。

【教學特別要求】

- 不要只整理精簡筆記，每個重要知識點都要有足夠的白話說明、具體例子與必要比較。
- **課文逐句解釋非常重要，不可以只整理段落大意而省略原文翻譯。**
- 文言文及古詩詞原則上依照每個「。」分句，逐句提供原文、翻譯、字詞解釋及句意分析，標點應尊重原教材。
- 如果原文出現省略、倒裝、借代或特殊文言語法，應另外說明真正意思。
- 詩詞除了字面翻譯，也要解釋意象、情境、情感與作者想表達的深層意思。
- 採用「了解背景 → 逐句閱讀 → 理解字詞 → 掌握段落 → 理解主旨 → 記憶考點 → 題目練習 → 錯題複習」的教學方式。
- 每個重要知識點都盡量搭配理解檢查題，避免學生只背答案。
- 對於容易混淆的字義、修辭、文體及國學常識，要使用比較表協助記憶。
- 老師上課強調的重點、口訣及考題提醒應優先整理。
- 每道選擇題都應解釋錯誤選項的問題所在，教學生如何排除干擾答案。
- 閱讀測驗要教會學生「找出題目關鍵字 → 回到文章找依據 → 分析上下文 → 排除錯誤選項」。
- 課文原文、作者、年代、注音、字義、典故、翻譯及答案必須正確。
- 必須區分原文事實、作者觀點、後人詮釋與老師補充，不能將推測說法當成確定事實。
- 不清楚或無法辨識的教材內容，不得自行猜測為正確答案。
- 自行新增的教學例子與模擬題必須明確標示，不能冒充課本或老師原題。
